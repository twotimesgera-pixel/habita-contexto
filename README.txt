HABITA CONTEXTO PWA - MAPAS Y PDF

PRUEBA LOCAL
1. Abre una terminal dentro de esta carpeta.
2. Ejecuta: python -m http.server 8080
3. Visita: http://localhost:8080

MAPAS
- El mapa interactivo usa Leaflet y teselas de OpenStreetMap.
- Pulsa "Usar mi ubicación" para colocar el terreno mediante GPS.
- También puedes arrastrar el marcador para ajustar las coordenadas.
- El mapa necesita Internet; el resto de la app sigue disponible sin conexión después de la primera carga.

PDF
- Pulsa "Exportar informe a PDF".
- En el cuadro de impresión elige "Guardar como PDF".
- El informe incluye métricas, plano contextual, mapa y recomendaciones.

INSTALACION
- Windows: abre con Microsoft Edge y usa Aplicaciones > Instalar Habita Contexto.
- Android: publica esta carpeta mediante HTTPS, ábrela con Chrome y selecciona Instalar aplicación.
